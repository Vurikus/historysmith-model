# Генерация мира

Корневой элемент — объект с массивом `raws`. Каждый продукт из `model/craft/product.json` должен встречаться ровно один раз и содержать поля `modelName` и `frequency`, где `frequency` — число в диапазоне [0, 1].

Частота задаёт целевую долю всех тайлов мира, содержащих продукт: 0 отключает размещение, 1 задаёт размещение на каждом тайле. При размещении целевое количество тайлов округляется; фактическое размещение ограничено доступными местами обитания с подходящими климатом и типом местности, а также вместимостью тайла для каждой категории. Частоты независимы и не нормализуются до суммы 1. Для произведённых товаров и домашнего скота частота равна 0. Каждое размещённое месторождение изначально содержит 1000 единиц ресурса (значение задаётся в игровых константах сервера).
